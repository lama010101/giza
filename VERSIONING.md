# Versioning

Releases follow [Semantic Versioning](https://semver.org/).

- Application releases are tagged `vX.Y.Z`.
- Specification versions are tagged `spec-vX.Y` independently.
- The changelog is generated from Conventional Commits.

## Branches

- `master` — current stable line.
- `vX.Y` — maintenance branches for older releases (if needed).
- `feat/*`, `fix/*`, `docs/*`, `refactor/*` — short-lived work branches.
